# Lancer Built For Me — build-your-piece form

Public page that the QR code on Lancer Built For Me POP opens. Anyone can build a piece
(sectional or sofa/chair/sleeper), then Print / Save PDF and bring it to a Lancer dealer.
No pricing, no saving to a server. A draft is kept in the visitor's own browser until they press "Start over".

- Options, item codes and sizes: Lancer Built For Me program sheets, October 2023
  (lancerfurniture.com/built-for-me). Update `PROGRAMS`, `ARMS`, `BACKS`, `LEGS`, `FINISHES` in index.html if the sheet changes.
- Option pictures are cropped from `bfm-sheet.jpg` (page 1 of Lancer's Oct 2023 sheet, 1500×2471).
  Lancer's site blocks hotlinking, so the file must live in this repo. Without it, tiles show labels only.
- Logo: lancer-logo.svg (new Lancer logo, Oct 2026).
- QR: qr-built-for-me.png / .svg → https://zangarano.github.io/lancer-built-for-me/
  (regenerate if the page moves to another address).
